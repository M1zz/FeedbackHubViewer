마인드맵

  • DeployBar개발자 혼자 쓰는 메뉴바 배포 도구 (미출시)
    • 문제
      • 앱 수십 개를 스토어에 올리는 일이 매번 손이 너무 많이 간다
        • 앱마다 빌드·업로드·심사 제출을 반복한다
        • 언어마다 릴리즈노트와 스토어 문구를 채운다
        • 어느 앱이 왜 막혔는지 한눈에 안 보인다
        • 심사 결과를 웹에 들어가 봐야 안다
    • 타겟
      • Mac에서 앱 30여 개를 혼자 관리하는 개발자 본인
        • 새 버전을 여러 앱에 한꺼번에 올릴 때
        • 폰으로 원격에서 배포를 시키고 싶을 때
        • 심사 통과·거절 소식을 기다릴 때
      • 노리지 않는 사람 · 일반 사용자, 앱이 하나뿐인 개발자
    • 솔루션
      • 버튼 하나로 점검부터 업로드·심사 제출까지 끝낸다
        • 앱마다 막힌 이유와 푸는 법을 바로 표시
        • 모든 언어 릴리즈노트·문구·그림 올리기
        • 남은 일을 지시문으로 복사해 맡기기
        • 15분마다 심사 상태 확인 후 알림
        • 폰에서 명령 한 줄로 배포 시작
    • 결제까지
      • 1 발견 · 스토어에 내지 않은 개인용 도구다
        • 외부 사용자가 찾을 길이 없다
        • 레포를 Xcode로 열어 직접 실행
      • 2 스토어 페이지 · 스토어 페이지 없음 (미출시)
        • 스토어 문구·릴리즈노트 파일 없음
        • 설명은 README가 전부
      • 3 첫 실행 · 메뉴바 아이콘을 누르면 앱 카드가 뜬다
        • 작업 폴더의 앱을 저절로 찾아 등록
        • 상태 점: 잠김·심사 중·배포 가능
        • 헤더의 ? 버튼이 사용법
      • 4 첫 성공 · 버튼 한 번에 업로드부터 심사 제출까지
        • 막힌 앱은 이유와 할 일을 한 줄로
        • 자동 설정 버튼으로 빠진 설정 채움
        • 남은 항목은 해결 지시문으로 복사
      • 5 다시 찾기 · 상태가 바뀌면 배너로 먼저 알려 준다
        • 출시됨·심사 통과·거부됨 소식
        • 앱을 꺼도 알림이 남아 있음
        • 폰 원격으로 배포 가능 목록 확인
      • 6 결제 벽 · 아직 결제 장치 없음

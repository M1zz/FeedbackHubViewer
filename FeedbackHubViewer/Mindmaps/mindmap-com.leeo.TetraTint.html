마인드맵

  • TetraTint내 브랜드 색을 다크·고대비에 맞춰 주는 맥 도구
    • 문제
      • 기본 색은 다크 모드에 맞춰지는데 내가 정한 색은 그대로다
        • 다크 모드 색을 감으로 고르게 된다
        • 고대비 버전은 매번 그냥 건너뛴다
        • 색맹인 사람에게 어떻게 보일지 모른다
        • 직접 넣은 글꼴은 글자 크기를 안 따라간다
    • 타겟
      • 아이폰·맥 앱을 만드는 개발자와 디자이너
        • 다크 모드에서 내 앱 색만 어색해 보일 때
        • 스토어 접근성 표기의 '충분한 대비'를 채울 때
        • 브랜드 색 팔레트를 새로 잡을 때
        • 큰 글씨 설정에서 화면이 깨질 때
      • 노리지 않는 사람 · 앱을 만들지 않는 일반 맥 사용자
    • 솔루션
      • 색 하나로 네 가지 모드 색을 만들고 바로 내보낸다
        • 라이트 색 하나로 다크·고대비 포함 4가지 생성
        • 색 목록 붙여 넣으면 대비 합격 여부 판정
        • 색맹 시뮬레이션과 헷갈리는 색 쌍 경고
        • 직접 넣은 글꼴용 글자 크기 대응 코드
        • 저장한 색 전체를 한 번에 내보내기
    • 결제까지
      • 1 발견 · 개발자 모임에서 '내 색은 왜 안 바뀌나' 공감
        • 인스타 '브랜드 컬러는 다크 모드를 모른다'
        • 쇼츠: 색 하나에 네 모드가 동시에 뜨는 장면
        • 레딧 개발자 게시판, 디스콰이엇 소개글
        • 맥 앱스토어에서 색상대비·WCAG 검색
      • 2 스토어 페이지 · 부제 '커스텀 색상·폰트를 다크·고대비에 맞춰 변환'
        • 애플이 안 해 주는 일을 대신한다는 설명
        • 기능 여섯 가지를 차례로 소개
        • 맥 전용, 24개 언어
      • 3 첫 실행 · 저장한 색이 없으면 시작 안내가 뜸
        • 도움말 메뉴에서 안내를 다시 볼 수 있음
        • 화면에서 색 집기 팁 풍선
        • 색맹 미리보기 팁 풍선
      • 4 첫 성공 · 내 색을 넣자 네 모드 색이 나란히 뜸
        • 고대비는 흰 배경 4.5:1, 검은 배경 7:1
        • 마음에 안 드는 변형은 색 고르기로 손봄
        • 색상 파일이나 코드로 바로 내보내기
      • 5 다시 찾기 · 새 앱·새 화면을 만들 때마다 꺼냄
        • 저장한 브랜드 색 팔레트가 남아 있음
        • 기본 색 값을 클릭 한 번에 복사
        • 단축어 앱에서 화면 색 집기
      • 6 결제 벽 · 아직 결제 장치 없음
        • 모든 기능이 무료로 열려 있음
      • 7 결제 · 아직 결제 장치 없음
        • 앱 설정에 무료 앱으로 지정되어 있음
        • 판매 상품 없음

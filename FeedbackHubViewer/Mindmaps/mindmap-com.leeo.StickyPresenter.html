마인드맵

  • StickyPresenter발표 화면 위에 대본과 타이머를 띄우는 맥 앱
    • 문제
      • 키노트를 전체 화면으로 띄우면 대본도 남은 시간도 안 보인다
        • 전체 화면에선 메뉴 막대 시계까지 사라진다
        • 시계를 힐끔대다 말이 끊긴다
        • 발표자 화면용 두 번째 모니터가 늘 있진 않다
        • 발표 중엔 맥에 손이 닿지 않는다
    • 타겟
      • 맥으로 발표하거나 강의하는 사람
        • 발표 시간을 넘겨 본 직후
        • 발표 시즌을 앞두고 리허설할 때
        • 강의실 뒤에서도 보일 타이머가 필요할 때
        • 대본을 읽어 줄 프롬프터가 필요할 때
      • 노리지 않는 사람 · 아이폰·아이패드로만 발표하는 사람 (맥 전용)
    • 솔루션
      • 전체 화면 위에도 떠 있는 메모와 카운트다운 타이머
        • 전체 화면 위 스티키 노트, 잠그면 안 바뀜
        • 끝이 다가오면 붉어지는 큰 타이머
        • 속도 조절과 좌우 반전 되는 텔레프롬프터
        • 어느 앱에서나 여는 단축키
        • 아이폰 리모컨 (별도 무료 앱)
    • 결제까지
      • 1 발견 · 발표 중 시계 보던 순간을 건드리는 글
        • 인스타 카드뉴스 '발표 중에 시계 보셨죠?'
        • 쇼츠 '키노트 전체 화면인데 대본이 보인다'
        • 네이버 블로그 따라 하기 글, 레딧 개발 이야기
        • 맥 앱스토어에서 발표타이머·텔레프롬프터 검색
      • 2 스토어 페이지 · 부제 '발표 화면 위 메모와 타이머'
        • 대본과 남은 시간 둘 다 한눈에라는 약속
        • 계정도 광고도 없고 노트는 맥 밖으로 안 나감
        • macOS 14 이상, 24개 언어
      • 3 첫 실행 · 메뉴 막대 아이콘과 시작 안내
        • Dock 아이콘 없이 메뉴 막대에만 뜸
        • 안내: 메뉴 막대 위치, 단축키, 로그인 시 실행
        • 기능별 사용 가이드가 열리고 도움말에서 다시 봄
      • 4 첫 성공 · 전체 화면 슬라이드 위에 노트가 그대로 보임
        • 복사해 둔 대본으로 바로 새 노트
        • 5:30처럼 적으면 타이머 시작
        • 끝날 즈음 붉게, 끝나면 소리와 깜빡임
      • 5 다시 찾기 · 발표·수업이 있을 때마다 켬
        • 로그인할 때 자동으로 열리게 설정 가능
        • 노트가 저장돼 다시 켜도 같은 자리
        • 25/5로 적으면 뽀모도로, 평소 집중용으로도
        • 알림 센터 위젯과 단축어 앱에서 바로 열기
      • 6 결제 벽 · 아직 결제 장치 없음
        • 모든 기능이 무료로 열려 있음
        • 할 일 목록에 '유료화 대비' 작업 기록은 있음
      • 7 결제 · 아직 결제 장치 없음
        • 앱 설정에 무료 앱으로 지정되어 있음
        • 판매 상품 없음, 마케팅 글도 '무료'로 소개

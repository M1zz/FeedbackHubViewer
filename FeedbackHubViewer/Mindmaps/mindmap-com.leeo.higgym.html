마인드맵

  • 앱 디자인 실습직접 만져 보는 앱 화면 설계 워크북
    • 문제
      • 앱 화면 규칙을 읽어도 왜 그런지 손에 남지 않는다
        • 버튼 하나 자리에도 근거를 대기 어렵다
        • 가이드 문서는 길고 그림만으로는 감이 없다
        • 디자인 리뷰에서 왜를 설명하지 못한다
        • 새 툴바·탭바·시트 동작을 직접 볼 데가 없다
    • 타겟
      • 화면 결정에 이유를 대고 싶은 앱 개발자와 디자이너
        • 툴바 버튼을 어디 둘지 막힐 때
        • 디자인 리뷰에서 근거를 요구받을 때
        • 포트폴리오 앱을 다듬으며 공부할 때
      • 노리지 않는 사람 · 앱을 만들지 않는 일반 사용자
    • 솔루션
      • 일부러 어긴 화면을 써 보고 적고 고친 화면과 비교하게 한다
        • 레슨 23편, 써 보기부터 배운 것 적기까지
        • 그림을 누르면 근거가 나오는 항목 68개
        • 실수 100편 회고와 원칙 7개
        • 설정을 바꾸면 판정해 주는 실습실 5종
        • 화면으로 판단하는 퀴즈 396문항
    • 결제까지
      • 1 발견 · UI/UX 공부·탭바·다크모드 같은 말로 검색
        • 키워드: 가이드라인, 접근성, 와이어프레임
        • 웹에 툴바 주석 문서가 공개돼 있음
        • 준비된 홍보 카드뉴스는 아직 없음
      • 2 스토어 페이지 · 읽지 않고 만져서 익히는 워크북
        • 부제: 직접 만져 보는 화면 설계 워크북
        • 무료로 레슨 3편 등 체험 범위를 밝힘
        • 주간·월간 구독, 평생 이용권 안내
      • 3 첫 실행 · 세 장 안내 뒤 학습 코스가 첫 화면
        • 처음 만지는 화면은 일부러 어긴 쪽이라 안내
        • 답보다 내 문장이 먼저, 다섯 단계
        • 계정·권한 요청 없음
      • 4 첫 성공 · 어색했던 화면이 고친 화면으로 바뀌는 순간
        • 같은 자리에서 어긴 화면과 고친 화면 교체
        • 내가 쓴 글과 이유를 나란히 봄
        • 배운 문장이 노트 탭에 쌓임
      • 5 다시 찾기 · 멈춘 레슨을 이어서 한 편씩 밟는다
        • 코스 화면에 다음 레슨 이어 하기
        • 단축어로 멈춘 레슨 바로 열기
        • 업데이트 뒤 새 기능 안내 한 번
      • 6 결제 벽 · 레슨 4편째를 열면 그 자리에 결제 화면
        • 무료: 레슨 3편, 실수 10편, 툴바 실습실
        • 퀴즈는 1장만, 훈련·실전 문제는 잠김
        • 잠긴 줄에는 자물쇠 Pro 표시
        • 항목 68개·원칙 7개·노트는 늘 무료
      • 7 결제 · 앱 디자인 실습 Pro, 세 가지 중 고르기
        • 주간 구독 2,900원 (시험용 설정 값)
        • 월간 구독 9,900원 (시험용 설정 값)
        • 평생 이용권 50,000원, 구독 아님
        • 무료판 설치자는 평생 Pro, 구매 복원 있음

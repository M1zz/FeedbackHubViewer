    • 문제
      • 신입 개발자는 남들이 다 겪은 실수를 직접 아프게 겪으며 배운다
        • 무엇을 조심해야 하는지 미리 알 길이 없다
        • 같은 실수를 몇 번이고 되풀이한다
        • 읽고 끝나는 공부는 내 경험으로 남지 않는다
        • 물어볼 선배가 없으면 혼자 끙끙 앓는다
    • 타겟
      • 막 일을 시작했거나 취업을 준비하는 주니어 개발자
        • 첫 회사에서 코드 리뷰로 지적을 받았을 때
        • 부트캠프를 마치고 취업을 준비할 때
        • 같은 실수를 또 해서 회고가 필요할 때
      • 노리지 않는 사람 · 이미 실수를 다 겪어 본 시니어 개발자
    • 솔루션
      • 흔한 실수 100가지를 상황·해결·배움으로 읽고 회고로 내 것으로 만든다
        • 10개 분야, 실수마다 상황·해결·배움 설명
        • 겪어 본 실수 체크와 분야별 진행률
        • 실수마다 회고 질문 4개, 모두 400개
        • 답은 회고 일지에 모여 다시 보기
        • 북마크, 아이폰·아이패드·Mac 동기화
    • 결제까지
      • 1 발견 · 개발 공부·커리어 관련 말로 검색해 만난다
        • 신입, 코드리뷰, 회고, 부트캠프 같은 검색어
        • 부제: 주니어 개발자 성장 체크리스트
        • 여러 나라 언어로 출시
      • 2 스토어 페이지 · 실수 100가지를 미리 알고 덜 아프게 배운다
        • 처음 30개는 무료라고 먼저 밝힘
        • 개인정보 수집·광고·분석 도구 없음
        • 월간·연간 구독 또는 평생 이용권 안내
      • 3 첫 실행 · 네 장 안내 뒤 분야 목록이 열린다
        • 실수 100, 체크리스트, 회고, 기기 동기화 소개
        • 가입 없이 바로 시작
        • 잠긴 분야 7개가 자물쇠로 보임
      • 4 첫 성공 · 겪어 본 실수를 체크하고 회고 질문에 답한다
        • 나도 이랬다 싶은 상황 설명
        • 이렇게 하면 된다는 해결 방법
        • 쓴 답이 회고 일지에 쌓임
      • 5 다시 찾기 · 진행률을 채우고 일지를 다시 본다
        • 분야별·전체 진행률 화면
        • 북마크해 둔 실수 다시 보기
        • 5·20·50개 체크 때 별점 요청
      • 6 결제 벽 · 무료 3개 분야 30개를 넘기면 잠긴다
        • 4~10번째 분야는 자물쇠, 누르면 결제 화면
        • 실수 70개, 회고 질문 280개가 잠김
        • 목록 위 PRO 배너와 설정에도 입구
      • 7 결제 · PRO 월간·연간 구독 또는 평생 이용권
        • 월간 3,900 · 연간 24,900 · 평생 39,900
        • 시험용 설정 값, 실제 스토어 가격은 미확인
        • 연간이 기본 선택, 인기 표시
        • 체험 기간 없음, 구매 복원 버튼 있음
